# Interactive Executive Dashboard

## Overview

An interactive executive dashboard built using React, Vite, Chart.js, and Bootstrap.

## Features

- KPI Cards
- Revenue Trend Analysis
- Department Performance Charts
- Interactive Department Filter
- Responsive Design

## Technologies

- React.js
- Vite
- Chart.js
- React-ChartJS-2
- Bootstrap 5
- GitHub
